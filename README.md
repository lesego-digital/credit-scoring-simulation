## credit-scoring-simulation
This project demonstrates how machine learning can be used to simulate credit scoring using the UCI Credit Card Default dataset. The model helps classify whether a customer is likely to default on their credit card payment.
This project demonstrates how machine learning can be used to simulate credit scoring using the UCI Credit Card Default dataset. The model helps classify whether a customer is likely to default on their credit card payment.

## 📊 Dataset
- Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/default+of+credit+card+clients)
- Format: Excel
- Features: Demographics, credit limits, payment history, bill amounts, and repayment status

## 🧠 Objective
To build a binary classification model that predicts credit default (Yes/No).

## 🔧 Tools & Libraries
- Python
- Google Colab
- Pandas, NumPy
- Scikit-learn
- Seaborn & Matplotlib

## 🧪 Model: Logistic Regression
- Accuracy: ~80–82%
- Evaluated with confusion matrix and classification report
- Used feature scaling and train-test split

## 📈 Visuals Included
- Countplot of default vs non-default
- Histograms for key features
- Confusion matrix heatmap

## 💡 Insights
- The model can help banks/fintechs assess risk and automate credit approval.
- Must be used responsibly to avoid bias or unfair exclusions.

## 🚀 To Run
1. Clone the repo
2. Open notebook in Google Colab
3. Upload the dataset (`default of credit card clients.xls`)
4. Run all cells
